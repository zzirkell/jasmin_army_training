# Exercise 01: Cows Only

## Goal
Create a simple `Cow` class and use it from `farm.py`.

No inheritance yet.

## Files

```text
starter_files/ex_01_cows_only/cow.py
starter_files/ex_01_cows_only/farm.py
```

## Task
A cow has `name`, `eyes`, `legs`, `speed`.

A cow can `moo()`, `run()`, and `describe()`.

In `farm.py`, create three cows: Bonya, Shusha, Molly. Put them in a list and loop over them.
