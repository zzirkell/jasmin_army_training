# 01 Classes: Farm Project

This module starts object-oriented programming with a small farm project.

The learning path is intentionally gradual:

1. one simple class: `Cow`
2. another similar class: `Sheep`
3. a `Farm` that stores lists of objects
4. farm methods that loop over objects
5. inheritance with `Animal`
6. abstract `Animal` as a contract
7. creating a custom animal
8. movement contract / interface idea
9. a second organizer class: `SummerAnimalCamp`
10. a mini OOP exam

## Important

Do not begin with getters/setters/static/final. First she should understand objects, attributes, methods, lists of objects, and inheritance.
