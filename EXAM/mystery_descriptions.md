# Mini Exam Before Classes

This mini exam checks whether you can use the basic Python tools before starting object-oriented programming.

No classes are needed here.

You should practice:

- variables
- strings
- numbers
- lists
- dictionaries
- sets
- conditions
- loops
- functions
- returning values
- using `main()`

## Rules

Try to solve each file without ChatGPT.

You can use:

- the mini cheatsheet
- old exercises
- Python Tutor
- Python documentation
- the example files from earlier exercises

You should not copy solutions.

## Exercise 1: Guinea Pig Food Planner

File:

```text
exam_01_guinea_pig_food.py
```

Theme: Bonya and Shusha.

You will calculate daily vegetable portions, count favorite foods, and decide whether the food plan is enough.

You need to implement:

```python
calculate_total_food(food_amounts)
find_favorite_foods(preferences, minimum_score)
is_food_plan_enough(total_food, required_food)
```

Concepts:

- dictionary
- list
- loop
- condition
- `sum`
- comparison
